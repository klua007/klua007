7. 🐛 **Nunca vi um bug sobreviver a três coisas:** café, borracha e uma boa noite de sono.
8. 📚 **Aprendo linguagem nova em dias** — a sintaxe muda, a lógica é sempre a mesma.
9. 🧠 **Tenho mais ideias de projeto do que tempo de vida** — minha lista de "e se eu fizesse..." não tem fim.
10. 🛹 **Vibe de rua, teclado na mão:** pra mim, código e arte são a mesma coisa — só muda a ferramenta.
